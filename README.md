# FitFlow Redesign

FitFlow is a fitness application redesign developed for IT3060 – Human Computer Interaction.

## Project Overview

FitFlow is designed to provide users with a seamless fitness experience through personalized workouts, progress tracking, nutrition tracking and community features.

The system also integrates AI services to provide personalized workout and nutrition recommendations.

## Key Features

- Personalized workout plans
- AI-powered workout recommendations
- Fitness progress tracking
- Nutrition tracking
- Community challenges
- Social sharing
- Real-time community updates
- Secure user authentication

## Technology Stack

| Component | Technology |
|---|---|
| Frontend | Flutter |
| Backend | NestJS |
| AI Service | Python FastAPI |
| Database | PostgreSQL |
| Authentication | AWS Cognito |
| Caching | Redis |
| Real-Time Communication | WebSockets |
| File Storage | AWS S3 |
